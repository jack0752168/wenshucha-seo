## 正文（发布用）

先说明一下：前面那位答主问的「前因后果呢、你给了多少他给了多少」，是对的，个案确实得看细节。
我不重复这个角度。

我自己在做法律检索这行（文书查），手上有一套裁判文书检索库。你这个问题我没法给你法律意见，
但我可以把这类案子在**已公开的裁判文书里长什么样**摆给你看——尤其是一件你现在多半还没意识到的事：
你想问的「他凭什么不经过我同意」，和法院实际在审的东西，**不是同一个问题**。

下面每一步我都把参数写出来，你可以自己照着走一遍。

### 一、我是怎么把这类案子筛出来的

搜索框里只丢「夫妻共同财产」四个字，全库命中 **6,581,008** 篇。这个数没有意义，
因为几乎所有涉及财产的民事判决都会提到这四个字。往下收：

```
只把「夫妻共同财产」丢进搜索框        6,581,008
+ 案由 = 离婚后财产纠纷                  74,038
+ 案件类型 = 民事                        72,044
+ 近 3 年                                7,080
```

到这里剩 **7,080** 篇。**但这 7,080 不能直接说成「这类案子有 7,080 件」**——
案由过滤是宽松匹配，它把相邻案由一起捞进来了。我们系统会做一次纯度体检，结果是：

```
真正标着「离婚后财产纠纷」    4,636   （纯度 65%）
同批混进来的：婚约财产纠纷    2,411
              离婚后损害责任纠纷  33
```

4,636 + 2,411 + 33 = 7,080，**一条不差**。所以真实可引用的数是 **4,636**，不是 7,080。
混进来的 2,411 是彩礼案子——彩礼判决书正文也天天写「夫妻共同财产」四个字，被同一个词捞进来很正常。

### 二、第一个数据才给得出的判断：这事**不在婚内被处理**

我把案由过滤去掉，只留 `q=夫妻共同财产 + 民事 + 近三年`，池子 **404,920** 篇，
看看这批案子都被贴了什么案由标签（同一个分母，才能横着比）：

```
 5. 离婚纠纷                 14,756
 ...
15. 离婚后财产纠纷            4,636
16. 赠与合同纠纷              4,602
...
24. 债权人撤销权纠纷           2,656
28. 婚约财产纠纷              2,411
29. 分家析产纠纷              2,397   ← 榜末
```

现在看你最关心的那个案由——**「婚内夫妻财产分割纠纷」**。
它是《民法典》1066 条给的那条路：**不离婚，婚内就要求分割共同财产**。

**它连前 29 名都进不去。** 第 29 名是 2,397，也就是说在这 404,920 篇里，
标着「婚内夫妻财产分割纠纷」的**少于 2,397 篇**；而「离婚后财产纠纷」有 4,636 篇。
**至少 1.9 比 1。**（我只能说「至少」，因为榜外的确切值我拿不到，
所以真实差距只会比 1.9 倍更大，不会更小。）

这个比例对你的实际意义是：**「不离婚，就这笔钱单独告一场」这条路，在裁判文书里是稀薄的。**
绝大多数同类争议，是**到离婚那一步、或者离婚之后才被翻出来算总账**的。
法条上 1066 条确实写着可以婚内分割，但它有严格前提（一方隐藏转移挥霍、或负有法定扶养义务却拒不治病），
「给了父母一笔钱」通常够不上。这不是说你没救。**要有心理准备：这件事更可能是作为将来清算里的一笔，而不是现在就能单拎出来打的一场官司。**

### 三、第二个判断：真要打，**被告可能不是他**

看上面那张榜单第 16 名——**赠与合同纠纷 4,602**，几乎和离婚后财产纠纷（4,636）一样多。

这是一条平行路径：**不告配偶，直接告收钱的那一方（公婆），主张这笔无偿赠与无效、要求返还。**
再往下第 24 名，**债权人撤销权纠纷 2,656**，对应的是撤销无偿处分那一路。

⚠️ 这三个数是**标签分布**，我只能告诉你「这三条路在库里各有多少篇文书」，
**不能**告诉你哪条赢面大——那需要逐篇读裁判理由，不是聚合数能回答的。
但至少它告诉你：这件事在实务里**不止一个诉法**，而只盯着「怎么让他把钱要回来」，
可能一开始就选窄了。

### 四、第三个判断，也是最扎心的一个：「擅自」这两个字，判决书基本不写

回到那 7,080 篇，我在结果里逐个加词看还剩多少：

```
+ 在结果中搜「擅自」      308
+ 在结果中搜「无偿」      211
+ 在结果中搜「赠与」    1,813
+ 在结果中搜「父母」    2,212
```

「擅自」只剩 **308**，占 4.3%。**也就是说至少 95.7% 的文书，通篇不出现「擅自」两个字。**

这里必须说清口径：我们的「在结果中搜」对正文是**分词 OR**，不是精确短语，
所以 308 是**上界**——真实只会更少，不会更多。这个方向是安全的。

对你的意义：你现在心里那句「他凭什么不经过我同意」，是一个**授权问题**；
而判决书里在处理的，大多是**金额、用途、是否属于日常家事代理范围、有没有实际转移**这些事实问题。
换句话说，**「没经过我同意」本身很难成为胜负手**，
夫妻一方对共同财产有日常家事代理权，小额、常规的支出根本不需要另一方点头。
真正决定输赢的通常是那个更土的问题：**这笔钱有多大，超没超出「日常生活需要」。**

### 五、剩下几个数，顺手给你

还是那 7,080 篇（记住可引用的精确数是 4,636）：

- **二审 1,308，占 18.5%。** 横着比一下我之前查过的：民间借贷 8.2%、彩礼 12.2%、劳动争议 33-35%。
  这类案子上诉率是中间档——比借钱的高，比劳动争议低得多。时间预算按「有可能打二审」做，但不必按 35% 那种概率去焦虑。
- **调解书 83 篇。** 占比 1.17%。这个数看着小，但在我查过的案由里算**偏高**的：
  物业费 0.19%、劳动争议万分之二点八、工伤私了千分之二点八。
  ⇒ 家事案件是少数**还真有人谈得成**的类型。别一上来就把话说死。
- **判决书 5,226 : 裁定书 557 ≈ 9.4 : 1。** 裁定书占比低，说明这类案子多数是实体审完给结论的，
  程序性驳回不算多——立案门槛不高。
- **地域**：北京 836 居首，**甘肃 520 排第二**，河南 515，辽宁 427，广东只排第五（418）。
  北京第一好理解，甘肃第二不好理解——我不打算替它编一个解释，
  这大概率跟各地文书上网比例有关，而不是甘肃人更爱打这个官司。**看不懂的数字就说看不懂。**

### 七、这些数字不能说明什么

得把边界划清楚，否则上面全是误导：

1. **一个胜诉率都没有，也给不了。** 聚合能数出「有多少篇文书」，数不出「多少人赢了」——
   那要逐篇读裁判理由。任何拿这种检索直接报「支持率百分之多少」的，都是在编。
2. **「在结果中搜」是分词 OR，不是精确短语。** 所以「擅自 308」只能当**上界**看，
   不能反过来说「有 308 个案子认定了擅自处分」。
3. **纯度只有 65%。** 我引用的是精确数 4,636，但你如果自己去点那个链接，
   页面会显示 7,080——差的那 2,444 是彩礼案和离婚后损害责任案。别被大数字骗了，包括别被我骗。
4. **只有已公开的文书。** 调解结案的大多不上网，撤诉的看不到，
   还有相当比例的判决压根没公开。**库里的样本天然偏向「谈不拢、走完了程序」的那一批**，
   这个偏差的方向和大小我都算不出来。
5. **近三年只有 4,636，切细了就不够用了。** 再按省份、按金额段拆下去，
   每格几十件，那个粒度上的任何比例都是噪音，我不会去算。
6. **这不是法律意见。** 我是做检索工具的，不是律师，也没看过你家任何一份材料。
   你这件事真要动，找个当地做家事的律师，把工资流水、转账记录、时间线整理好再去谈。

最后：这套东西不是只有我们能查。中国裁判文书网自己就能搜，
北大法宝、威科先行也都做这个。我的建议是——**不管用谁家的，先看一眼它的纯度，再决定要不要信它给你的那个总数。**
