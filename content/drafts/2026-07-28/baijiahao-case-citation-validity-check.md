# 类案检索出来的判决还能不能引用？五道核验筛掉不能用的案例，律师可套用清单

类案检索捞出一堆判决之后，真正决定成败的是这一步：这份判决，现在还能不能引。捞得多而没做核验，等于把一堆没验过货的材料直接写进代理词——庭上被对方一句"该判决已被二审改判"打掉，比没检索到更被动。这篇不讲怎么搜，只讲搜到之后怎么筛：五道核验，每道给出具体做法和判断标准，文末附一份可以直接照着走的自查清单。

先给结论：一份判决能不能引用，取决于五件事——它自身的效力状态、它适用的法律是否还有效、它的位阶和地域是否够得着你的法庭、它和你的案子是不是真的可比、以及你要引的那句话是不是法院说的。五道里任何一道不过，这份判决就不该进你的检索报告。

## 一、为什么"捞到"离"能用"还差很远

裁判文书是一份**历史文件**，它记录的是某个时间点上某个法庭的判断。这个判断可能后来被推翻，它依据的法条可能后来被修订，它所在的法院可能根本管不着你现在这个庭。而这些信息，**大部分不写在文书正文里**。

核验这一步的意义就在这儿：把"这份判决存在"变成"这份判决现在对我的案子有说服力"。

顺带说一句类案检索的基础盘：全国裁判文书体量已是亿级规模（我们自己的库是 1.6 亿份量级），检索捞出几十上百份表面同类的判决毫不困难。**量从来不是瓶颈，筛才是。**

## 二、第一道：效力核验——这份判决自己还算不算数

一份一审判决被上诉、二审改判，判决书本身不会更新，它还是原样躺在库里，搜出来长得和生效判决一模一样。写进检索报告，对方律师做了这一步核验，庭上直接指出它已被改判——这一份的失分，会连带削弱你整份报告的可信度。

要核三件事：

**1. 这是几审，生效了没有。** 一审判决书上不会写"本判决已生效"。抓手是文书末尾的上诉权利告知：一审通常写明当事人可在期限内上诉；终审则写"本判决为终审判决"。看到上诉告知，就必须往下追。

**2. 有没有后续的二审、再审文书。** 做法是拿这份判决的**当事人名称 + 案由 + 案号关键信息**，回检索系统再搜一轮，看有没有同一批当事人在更高审级的后续文书。同系列案件的文书在库里通常各自独立，需要你主动去串。这一步花不了几分钟，能挡掉绝大多数"引用已被改判判决"的事故。

**3. 有没有被再审撤销或指令再审。** 再审的文书类型和一审二审不同（裁定、决定、再审判决），检索时不要把文书类型限死在"判决书"，否则会把再审裁定整个筛掉。

一条实操建议：**要对外引用的判决，效力核验必须做完；只作内部研究参考的可以放宽。** 区分清楚能省大量时间。

## 三、第二道：法源核验——它依据的法条现在还有效吗

判决是在当时的法律框架下作出的。法条修订、司法解释废止或替换之后，同样的事实，裁判结论可能完全不同。核三层：

**1. 引用的法律条文，现在的条号和内容。** 法典化和修订会带来条号平移：同一规则可能从旧法某条挪到新法另一条，内容还可能有实质调整。引用时必须做条号对应，并说明规则本身有没有变。只照抄旧条号，法官一看就知道没核。

**2. 依据的司法解释是否已被替换或废止。** 司法解释更新频率高于法律本身，旧解释被整体替代后，依据它形成的裁判思路未必还站得住。

**3. 新旧法衔接的时间节点。** 这条容易错：判决作出于新法施行之后，不等于它适用新法——法律事实发生在新法施行之前的，通常仍适用旧法。**所以看判决日期不够，要看正文实际援引的是哪一部法。**

筛的结论有三种：规则未变——照引；规则有实质变化——不引，或明确说明"该判决作出于规则修订前，此处仅引用其对某要件的分析思路"；规则已废止且无对应——弃用。第二种最考验功力。

## 四、第三道：位阶与地域核验——它够得着你的法庭吗

我国不是判例法国家，判决对后案没有当然约束力，但不同来源的说服力差别很大。核验的目的是给每份判决标出"分量"。从高到低大致几档：

- **指导性案例**：最高人民法院正式发布，要求各级法院审理类似案件时参照。一份对口的指导性案例，分量远超十份普通判决。
- **公报案例、最高人民法院本院裁判**：来源权威，实践中说服力很强。
- **本辖区高级人民法院裁判**：直接影响本地裁判尺度，说服力往往高于外省同类判决——哪怕外省那份论证更漂亮。
- **本地中院、基层院裁判**：对说服本院法官有实际作用，尤其同一法院自己作出过的判决。
- **外省普通判决**：可用来说明"这类问题的主流处理是这样"，不宜作主力依据。

**常见误区**：找到一份说理精彩的外省基层判决如获至宝，放在报告最前面。位阶决定它在法官眼里的权重，说理再好也补不上位阶差距——正确做法是放在支撑位置。

**反方向的误区是只看本地。** 本地同类案件若只有个位数，那点样本得出的"本地裁判倾向"并不可靠。合理做法是先在全国范围看清主流观点，再收敛到本辖区看本地尺度，两个结论一起呈现。

## 五、第四道：可比性核验——它和你的案子真的是一类吗

案由相同、罪名相同，绝不等于可比。核心是**把两个案件的争议焦点和要件事实摆在一起对，而不是对标签**。对四件事：

**1. 争议焦点是否同一。** 同为建设工程施工合同纠纷，争的是合同效力、工程价款结算方式，还是工期违约责任——这三类之间几乎没有参考价值。争点不同，后面都不用比。

**2. 要件事实是否对应。** 你主张的构成要件，那份判决里法院怎么认定的？很多"看起来一样"的案件，差就差在一个要件事实上，而结论恰恰由它决定。

**3. 举证格局是否相似。** 同样的争点，一方举了关键证据和没举，结果可能相反。若那份有利判决建立在"对方未能举证"上，而你的案子对方证据充分，这份判决对你没什么用，甚至会被对方拿去说明规则的另一面。

**4. 程序状态是否可比。** 一审全面审理、二审围绕上诉请求审理、再审围绕再审事由审理，说理范围本就不同。拿再审裁定里"不属于再审事由"的表述去论证实体规则，是很常见的误用。

判断可比性有个硬要求：**必须读"本院认为"那一部分**。文书开头是当事人身份信息、诉讼代理人、程序沿革和双方陈述，对判断可比性几乎没有价值；决定可不可比的东西全在裁判理由里。只扫标题和摘要就下判断，会同时误杀真类案、误收假类案。

## 六、第五道：说理核验——你要引的那句话，是法院说的吗

**裁判文书里的大部分文字不是法院的观点。** 结构大致是：当事人信息 → 原告诉称 → 被告辩称 → 法院查明事实 → 本院认为 → 判决主文。其中"诉称""辩称""上诉称""答辩称"都是**当事人主张的转述**，可能和法院最终判断完全相反。

从检索结果里复制一段看着完美契合你观点的话写进代理词，结果那段是被告答辩意见、法院明确不予采纳——这类事故不算罕见。用关键词检索时尤其容易撞上：关键词命中的往往就是当事人陈述部分，因为那部分表述更接近日常用语，也更接近你搜索时用的词。

核验方法很简单但必须做：**把要引的每一句，回到原文确认它出现在"本院认为"之后**，引用时标明出自裁判理由部分。

还要额外核一件事：**法院对你这个争点到底有没有真的说理。** 有些判决结论有利，但对关键争点只有一句结论性表述，没有论证过程。这种判决证明不了"为什么"，法官很容易用一句"个案情况不同"带过。**有说理链条的判决，一份顶十份。**

## 七、把核验结论写进检索报告

每份进入检索报告的判决，建议固定带这几项：案号、法院、裁判日期；审级与效力状态（写明是终审，还是一审且经核未见后续文书）；适用法律及其现行状态；争议焦点与本案的对应关系（一句话说清为什么可比，不写笼统的"案情类似"）；引用的裁判理由原文（注明出自"本院认为"）。

再加一条容易被忽略的：**把不利判决也放进去。** 检索报告的价值在于让决策者看清真实格局，只呈现有利案例等于把风险藏起来，到庭上再由对方揭开。存在相反裁判观点时如实写明并分析差异原因，专业度反而更高。

## 八、这五道核验里，工具能替你做多少

诚实地说：**能减轻，不能免除。**

检索系统能做的是把核验成本压下来——按当事人和案号快速串出同一系列案件的后续文书，让裁判理由部分单独可见、不必每份都从头翻到中段，把法条援引与现行条文做上对应。这些能把原本几十分钟的核验压到几分钟。

但**判断部分工具替不了**：争点是否同一、要件事实的差异是否实质、外省那份漂亮说理值不值得进报告——这些依赖对本案的理解，是律师的活。

**AI 辅助同理。** 让 AI 从长判决里定位裁判理由、提炼争点、比对法条，效率提升明显；但它给出的每一处引用仍须回原文核对，尤其要确认那句话确实出自"本院认为"，而不是从当事人陈述里摘的。核验这件事本身不能外包。

## 九、可套用的自查清单

写进代理词、检索报告、法律意见书之前，每份判决过一遍：

**效力**
- [ ] 已确认审级；是一审的，已回检有无二审、再审后续文书
- [ ] 已确认未被改判、未被再审撤销
- [ ] 检索时未把文书类型限死在"判决书"，裁定、决定一并看过

**法源**
- [ ] 援引的法律条文已核对现行条号与内容
- [ ] 依据的司法解释已确认未被废止或替换
- [ ] 已确认实际适用的是新法还是旧法（看正文援引，不看判决日期）

**位阶与地域**
- [ ] 已标注来源档位（指导性案例／公报／最高法／本辖区高院／本地／外省）
- [ ] 主力位置留给了高位阶与本辖区裁判
- [ ] 全国主流观点与本地尺度两个结论都看过

**可比性**
- [ ] 争议焦点与本案同一，不是只有案由相同
- [ ] 关键要件事实已逐项对应，差异已识别
- [ ] 举证格局相似，不是建立在"对方未举证"上
- [ ] 程序状态可比

**说理**
- [ ] 要引的每一句已确认出自"本院认为"之后
- [ ] 该判决对本案争点有实质说理，不是一句结论带过
- [ ] AI 或工具给出的引用已回原文逐条核对

**报告呈现**
- [ ] 案号、法院、日期三项齐全
- [ ] 相反裁判观点已如实写入并分析

---

检索的功夫在搜，办案的功夫在筛。捞回一百份判决不难，难的是敢把其中五份写进代理词、并且经得起对方逐份核。这五道核验做熟之后，二十来分钟就能过完一批，但它挡掉的是庭上最难挽回的那一类失分。
