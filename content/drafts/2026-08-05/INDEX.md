## 本次发布链路新发现（已同步进 PLATFORM-PLAYBOOK）

08-04 记的「派发 animationend 解开弹框」这次**不管用**——本次弹框卡在 `cheetah-zoom-appear-prepare`（比 08-04 的 `-active` 更早一级），补派发 animationstart／animationend 都不推进，opacity 恒为 0。
根因同为后台分页 `visibilityState === 'hidden'` 导致 rAF 被暂停，且实测 `await new Promise(r=>requestAnimationFrame(r))` 直接 45 秒超时（渲染帧完全不推进）。
**通用破法（比派发事件更根本，建议今后首选）**：进编辑器后先把 rAF 打补丁成 setTimeout —
```js
window.requestAnimationFrame = cb => setTimeout(() => cb(performance.now()), 16)
window.cancelAnimationFrame = id => clearTimeout(id)
```
打完补丁后弹框立刻自行跑完入场动画（opacity → 1），后续「AI封图」标签、生成、确定全部一次通过。
