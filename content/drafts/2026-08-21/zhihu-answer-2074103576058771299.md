# 在上班途中因闯红灯受伤，是否能被认定为工伤呢？
> qid 2074103576058771299（最新问题 · 0 浏览 / 0 回答 / 0 关注 · 抢首答）
> 全新方向：账号 26 篇零行政案件，本篇 caseType=行政
> 新招式：把「问法太具体、公开数据只剩 23 条」这个检索失败当主结论

这题刚挂出来还没人答。我就不走法条科普那条路了——那种回答你随手一搜有几十个，都在抄《工伤保险条例》第十四条，抄得也没错，但对你没用。

先交代立场：我自己在做裁判文书检索这行（文书查），下面每个数字都是从我们自己的库里现跑的，参数我一条条写出来，你可以照着复现。

结论先摆着：你这个问法，公开裁判文书给不出统计答案。我把它原样输进去，最后只剩 23 条。下面是我怎么跑到 23 的。

一、筛选面板，一层层加

只把「上下班途中」丢进搜索框，610,659 条。
案件类型选「行政」，41,624 条。
时间选近三年，3,122 条。
打开「隐藏公告」，还是 3,122 条——没变，说明这批里没有公告类文书混进来。
在结果中搜「交通事故」，2,195 条。
在结果中搜「闯红灯」，23 条。

第二步为什么选「行政」而不是「民事」，这一步选错后面全错：工伤认不认，是人社局做的行政确认；你不服，告的是人社局，走的是行政诉讼。同一个词在「民事」下面有 362,518 条，那是另一批案子——劳动争议、赔偿怎么分担，不是「能不能认定成工伤」这个争点。

二、那个 23，是本篇最要紧的数

先说清它的性质：我们的「在结果中搜」对正文是分词匹配，不是精确短语。所以 23 是个上界，里面还可能混着「没有闯红灯」「不存在闯红灯行为」这类表述。真正踩在你这个情形上的，比 23 还少。

近三年全国公开的行政判决里，正文同时够得着「上下班途中」和「闯红灯」的，就二十几份。这个量级，我没法给你任何「多少比例能认定」。谁要是张口给你一个百分比，你先问他分母是多少、「有没有闯红灯」这个字段他是怎么提取的。

我不给统计。但这二十几条我能打开看，下面的东西是从里面读出来的。

三、能用的是结构数据

先看 3,122 条这一批的审理程序：

一审 1,233
二审 1,660
再审 56

二审比一审还多。

这是我跑过的所有类别里唯一一次出现这种情况。同样口径横着比一下：民间借贷的二审占 8.2%，刑事案件里提到取保候审的那批只有 4.4%，劳动争议在 33% 上下，工伤赔偿那类 41.4% 已经算很高了——这一批是 1,660 比 3,122，过半。

对你的实际意义很直接：这类案子基本是两审起步。不管一审谁赢，另一方大概率会上诉。时间预算、心理预期、请律师的费用怎么安排，都要按打完两审去算，别按「一审赢了就结束」去算。

法院层级也在印证：中级法院 1,543 件，比基层法院的 1,287 还多。

再看文书类型：

判决书 2,089
裁定书 208
调解书 0

调解书是 0。不是很少，是一件都没有。

行政诉讼原则上不适用调解，法律上就是这么定的，数据只是把它照了出来。意思是：这件事没有「跟人社局谈个折中数」这个选项，要么认定要么不认定，你只能把程序走完。这跟民事案子的思路完全两样——我之前跑劳动争议，调解书占比虽然低到千分之四那个量级，但它存在。这里是零。

还有一件事，是我翻那二十几条的当事人栏才注意到的：排在最前面的，多数是用人单位，不是受伤的人。

苏州某金属制品有限公司，对苏州市吴江区人社局。
东莞市明某家居用品有限公司，对东莞市人社局。
浙江蓝英保安服务有限公司，对瑞安市人社局。
河南省某保安公司，对商水县人社局。

这说明人社局认定了工伤，事情往往还没完，公司会接着告，「认定下来」和「拿到钱」中间还隔着一段。反过来，要是人社局没认定，那就是你去告。你得有个心理准备：对面通常是有法务或者代理律师的公司，另一边还站着一个行政机关。

四、必须说的一个数据缺陷

这批案子的案由是散的。同一类纠纷，不同法院登记成不同案由：

行政确认 847
劳动和社会保障行政管理（劳动、社会保障） 818
工伤保险资格或者待遇认定 550
行政复议 260

三千多条里，光这四个就分掉 2,475，讲的其实是同一件事。另外还有 184 条压根没有案由标签。

所以我不会跟你说「这类案子有 3,122 件」——我不敢保证这 3,122 条全是工伤认定争议。前三个案由那 2,215 条是明确的，行政复议那 260 条大概率也是，但我没有逐条核过。这件事对你也有用：你要是自己去查，只按某一个案由筛，会漏掉一大半。按关键词加案件类型筛，比按案由筛靠谱。

五、几份可以自己核的真实文书

（2023）苏0506行初388号，江苏省苏州市吴中区人民法院，行政确认。
（2023）粤19行终122号，广东省东莞市中级人民法院。
（2023）浙03行终813号，浙江省温州市中级人民法院，工伤认定二审。
（2024）苏12行终333号，江苏省泰州市中级人民法院，工伤保险资格或者待遇认定。
（2023）京03行终1492号，北京市第三中级人民法院。

看这类文书有个省时间的办法：别从头读，直接翻到「本院认为」那一段。这类案子的争点几乎都压在同一个地方——交警出的那份《道路交通事故认定书》，把责任划给了谁。法院一般不自己重新认定交通责任，它看的是那份认定书怎么写。

顺带说明一句：中国裁判文书网 2021 年之后要登录加验证码，没有稳定的公开原文直链，所以我给不了「点开直达原文」的东西，我们自己的产品页上也是这么写的。上面这些案号你拿去文书网自己搜，或者用任何一家检索工具，都能查到。

六、回到你问的那件事

我不是律师，这一段只是把《工伤保险条例》第十四条第（六）项的原文说清楚，不构成法律意见。

上下班途中认定工伤，条文写的是「受到非本人主要责任的交通事故」。

所以真正卡住你的，不是「闯没闯红灯」这个动作本身，而是交警在事故认定书上把主要责任划给了谁。闯红灯通常会导致本人承担主要责任甚至全部责任，一旦是这样，就不符合「非本人主要责任」，这条路走不通。但如果对方还有酒驾、超速、逆行这类情节，责任划分未必就是你全责——同等责任、次要责任的情形，条文上是够得着的。

所以第一件该做的事，是去把那份《道路交通事故认定书》拿到手，看责任那一栏怎么写。这一张纸的分量，比在网上问一百句都重。对认定书不服，它本身有复核程序，也是有时限的，越早看越好。

上面那批数据的链接在这儿，点开就是同一批结果：

https://tob.wenshucha.com/cases?q=上下班途中

进去以后把案件类型点成「行政」、时间点成近三年，就是我说的 3,122 条；再在结果里搜「闯红灯」，就是那 23 条。你自己动手收窄一遍，比看我描述有用。

七、这些数字不能说明什么

第一，全都是文书数量的分布，不是认定率，更不是胜诉率。我给不出「多少比例认定成功」，前面解释过分母的问题。

第二，那 23 条是分词匹配的上界，不是精确命中，真正跟你情形一样的更少。

第三，只有已经公开上网的文书在库里。这批数据近一年只有 701 条，近三年 3,122 条——近年的文书上网量明显在往下走，所以别把「近一年少」读成「这类案子变少了」，那是公开率的问题，不是案件量的问题。另外近五年和近三年都是 3,122，说明这个切片再往前基本没有增量，覆盖是有边界的。

第四，行政诉讼只是这件事的最后一段。绝大多数工伤认定在人社局那一步就定了，没进法院的根本不产生文书——而那部分恰恰是我这个库看不见的。拿判决书去推断整体情况，本身就是偏的。

第五，这不是法律意见，我也不是律师。你能不能被认定，取决于事故认定书的责任划分、有没有劳动关系、走的是不是合理的上下班路线、时间合不合理——这些我一个都不知道。

最后说一句：这个查法不是我们独有的，中国裁判文书网、北大法宝、威科先行、Alpha 都能做类似的事，你手边有哪个就用哪个。重点不是用谁的库，是别只看条文——把跟你情形最接近的那几份判决的「本院认为」读一遍，你对自己这件事的判断，会比现在清楚得多。
