# 打官司赢了却拿不到钱，问题真的出在执行阶段吗？

- 平台：知乎专栏
- 来源：2026-09-03 银行稿 zhihu-caichan-xiansuo.md，09-09 判缓（与当日另一篇钩子同题），09-10 补数据脊柱后重发

## 正文（发布用）

结论先说：多数时候不出在执行阶段。案子能不能拿到钱，在起诉那一刻多半就已经决定了，执行阶段能补救的空间比大家想象中小得多。

一、执行阶段其实没有多少新东西可做

进了执行程序，法院能做的动作是固定的：网络执行查控系统跑一遍银行、不动产、车辆、证券、股权，查到就控制，查不到就问你要财产线索。最高人民法院《关于民事执行中财产调查若干问题的规定》第一条写得很直白——执行过程中，申请执行人应当提供被执行人的财产线索。

也就是说，法院自己那一遍是标准动作，做完就到头了。剩下的靠你提供线索。而线索这个东西，不是等到胜诉判决拿到手那天才开始找的。

二、真正的分水岭在起诉之前

被告知道自己要被起诉，和被告已经收到判决书，是两种完全不同的状态。中间隔着几个月甚至一两年，足够把名下能动的东西动完。

所以有经验的做法是把顺序倒过来：先摸清对方有什么，再决定要不要诉、诉多少、要不要在起诉的同时申请保全。摸不到任何东西，这个案子的价值判断本身就要重估——不是不能打，而是要提前告诉当事人，赢了之后大概率还有一段很长的路。

三、这件事在数据里长什么样

上面两段是经验判断，下面是能核的数。以下都是写这篇时从 1.6 亿份公开裁判文书里现跑出来的。

正文里出现“财产线索”这四个字的文书，全库 10,509,874 份。随机抽五份看命中位置，五份全落在执行裁定书里同一个句式上：法院查控跑完、没查到东西、告知申请执行人、申请执行人提供不出其他财产线索、终结本次执行。也就是说，这一千多万份文书记录的正是“赢了拿不到钱”这件事本身，而且它们的结尾几乎都指向同一个环节——线索由谁提供。

四个可以自己核的案号：

（2021）川0184执1939号，劳务合同纠纷
（2022）鲁0116执42号，借款合同纠纷
（2023）鲁0112执3405号，票据纠纷
（2019）皖1226执2088号，无案由

把这一千多万份按案由拆开，第一格是“无案由”，5,840,369 份，占 55.6%。往下依次是借款合同纠纷 1,385,915 份、买卖合同纠纷 540,890 份、民间借贷纠纷 239,666 份、合同纠纷 201,992 份。

那个 55.6% 值得单独说一句。全库 1.6 亿份里案由为空的是 76,213,116 份，占 47.5%——执行类文书的案由填充比全库平均还要差。原因不难理解：执字号文书的案名常常只写“执行裁定书”，没有实体案由可填。所以想用案由这个筛选项去圈执行案件，这条路本身就不成立，只能靠正文关键词，再配案件类型、近三年、省份这些维度去绕。

深链在这里，可以自己去点（关键词“财产线索”加案由借款合同纠纷加民事加近三年）：

https://tob.wenshucha.com/cases?q=%E8%B4%A2%E4%BA%A7%E7%BA%BF%E7%B4%A2&cause=%E5%80%9F%E6%AC%BE%E5%90%88%E5%90%8C%E7%BA%A0%E7%BA%B7&caseType=%E6%B0%91%E4%BA%8B&lastYears=3&province=

打开后落地显示的是“共 381,699 篇”，和上面那个 1,385,915 不是一个数。差别来自两处：一是多加了近三年和民事两个限制，二是关键词框做的是分词后的并集匹配，不是短语匹配。同一批案子，加不加限制、按短语数还是按分词数，出来就是不同的数。谁给你一个数，先问它是哪种口径。

四、有两个数我查了，但不敢用

“终结本次执行程序”，按严格短语查，全库只返回 382 份。“未发现可供执行的财产”，返回 0 份。

这两个数都是假的。把它们丢进分词器看一眼：前者切成“终结 / 本次 / 执行 / 行程 / 程序”，“执行”和“行程”共用了中间那个“行”字；后者切成“未发 / 发现 / 可供执行 / 可供 / 执行 / 的 / 财产”，同样重叠。而短语匹配要求各个词的位置连续，一旦重叠就永远匹配不上。

上面那个 10,509,874 之所以敢用，是因为“财产线索”切出来只有“财产”和“线索”两个词，不重叠。

所以看到一个小得离谱的数，先别急着下结论，去看分词。这类假零不会报错，它只是安静地给你一个 0。

五、公开的裁判文书是起诉前少数几个能自己动手的地方

调查令要立案之后才能申请，查控系统只有法院能用。起诉前你能自己动的，主要是工商登记、不动产公示信息，以及公开的裁判文书。

裁判文书这一条经常被低估，因为大家翻的位置不对。几个具体的地方：

判决书的“本院查明”段落，而不是“本院认为”。查明段记录的是当年争过的事实，房屋坐落、车辆号牌、股权比例、账户开在哪家银行，都写在那里。离婚析产、股权转让、以物抵债、建设工程结算这几类案子尤其密集。

执行类文书不是判决书。执字号、执保字号、执异字号对应的是裁定书和通知书，检索时文书类型默认勾着判决书，这些会被整片挡掉。执行裁定写的是法院实际动过的手：查控了哪些账户、扣划了多少、查封了哪处房产。

对方作为原告的那些案子。北京市第一中级人民法院在公开的普法文章里专门点过这一条：通过检索裁判文书，可以查询被执行人是否有胜诉债权。别人欠他的钱，同样是可供执行的财产，但绝大多数人只搜对方当被告的方向。

判决书里顺带写清的关联关系。某某系某公司股东、法定代表人、实际控制人，某某为该笔债务提供连带责任保证——这些是判决说理必须交代的身份事实，拿到名字再搜一轮，线索能从个人扩到关联主体。

六、这条路的局限，必须说清楚

第一，它有滞后性。裁判文书记录的是判决作出那一刻的状态，两年前判决里的那套房子，现在很可能已经不在了。它是线索，不是现状。

第二，它不完整。执行类文书的公开比例明显低于判决书，涉及个人信息的部分还会做技术处理，账号通常只保留后几位。查不到不等于没有。

第三，它不能直接当证据。从公开文书里看到的财产信息，作用是让你在申请调查令或者向法院提交财产线索时能写出具体指向——哪家银行、哪个楼盘、哪家公司的股权，而不是笼统地写“请依职权调查”。真正的查控动作由法院完成，这条边界不能越。

第四，有一类东西永远查不到：现金、没有登记的动产、借他人名义持有的资产。指望公开文书解决这些，方向就错了。

第五，本文所有的数都只是“已公开文书里的数”。执行类文书的公开率本来就低于判决书，这是数据边界，不是可以靠更好的算法补上的东西。而且上面那些分布不是胜诉率，也不是执行到位率，它是观察不是统计——一千多万份里写着“提供不出财产线索”，只能说明这句话被写下来过一千多万次，不能反推现实中有多少比例的债权最后落了空。用案由做的任何统计还要再打一层折扣，因为分母里有一半以上是空案由。

七、所以那个问题该怎么回答

“赢了拿不到钱”这件事，追责到执行阶段通常没什么用，因为执行阶段的动作空间本来就窄。值得改的是更前面那一段：在决定起诉之前，花上半天把公开渠道能查的都查一遍，得出的可能是一份线索清单，也可能是一个“什么都查不到”的结论——后者同样有价值，它让你和当事人对这个案子的预期从一开始就是对的。
